# 文献书架

## 免环境桌面包

发布版本自带 Python、Qt 与 PDF 读取组件，无需安装 Python 或配置开发环境。Windows 解压后双击 `LiteratureShelf.exe`；macOS 提供 Apple Silicon / Intel 的 DMG；Linux 提供适用于现代 x86_64 桌面的 tar.gz。详见 [使用说明](packaging/QUICK_START.md)。

GitHub 的 **Actions → Desktop packages → Run workflow** 会在四台对应系统的构建机上自动打包并测试，每个任务的 Artifacts 中可下载对应平台的成品。推送 `v` 开头的版本标签会自动构建并发布到 Releases。macOS 包未公证，系统可能要求首次确认来源；不应关闭全局安全保护。

开发者本地构建：安装 `requirements-build.txt`，运行 `python packaging/build_release.py`。输出在 `release/`；构建会运行封包后的程序验证启动、PDF 读取、分类和搜索，不包含用户文献或 API 密钥。

本地 Windows 桌面文献管理工具。双击 **启动文献书架.bat**，或运行 `python app.py`。需要 Python 3.10+。新版采用 PySide6，提供浅色侧栏、渐变统计卡片、可调整宽度的文献列表与详情面板。本机 PDF 和界面依赖已放在 `.vendor` 中；换电脑后可执行 `python -m pip install -r requirements.txt`。

已打开旧版窗口时，请关闭旧窗口，再双击启动文件。新版继续读取原来的 `data/library.sqlite3`，无需重新添加文献。旧版界面代码保留在 `legacy_app.py` 供回退使用。

## 使用

1. 点击“添加文献”，可多选 PDF、DOCX、TXT、MD。程序保存绝对路径索引，不复制或移动原文件；重复路径自动跳过。
   也可以从资源管理器将一个或多个文件拖到“概览”或“文献目录”窗口中。拖入时顶部显示提示，松开后自动添加并按当前设置整理。重复文件自动跳过；混合拖入时仅接收支持的本地文献，忽略文件夹、不支持的格式和网页链接。当前批次正在整理时会提示等待，完成后可继续拖入。
2. 默认使用 `模型接口/api.json` 中的 OpenAI 兼容接口，添加后自动提取并整理。左下“阅读与接口设置”或齿轮按钮可以打开设置，在“阅读与整理”中改为本地规则或手动。
3. 左侧按“大类 → 小类”浏览，也可查看“待整理”。中央支持搜索题目、摘要、关键词、总结、分类与路径，并可按添加时间或题目排序。右侧分“总结 / 摘要 / 文件”查看详情。Ctrl / Shift 多选后点击“整理”可批量处理。
4. “编辑”可修正题目、摘要、引言、结论、局限、两级分类和总结，并添加个人描述与关联链接。手动保存不会自动触发模型；再次整理会重新生成总结，保留个人描述、链接和已锁定的手动分类。
5. 双击列表或点击“打开”打开原文件。列表右下“…”中的“本次打开方式”临时选择；设置中的“阅读与整理”可长期选择系统默认、浏览器或指定 `.exe` 阅读器。浏览器是否预览取决于文件类型和浏览器支持。
6. 原文件移动后，通过“…”菜单的“重新关联原文件”修复路径。“移除索引”不会删除原文件。“导出全部索引 JSON”便于查看或备份元数据。

## 大量文献与界面布局

- **收起大类**：点击左侧分类大类的名称或箭头即可收起／展开小类。收起状态在刷新和重开程序后保留。选中分组后也可使用左右方向键，空格切换展开状态。
- **独立目录页**：左上“概览 / 文献目录”切换界面。“文献目录”按“大类 → 小类 → 文献”浏览，点击分组展开，单击文献查看预览，双击打开原文。可搜索、编辑、批量整理，或通过“…”进行其他操作。
- **避免过长列表**：概览每页显示 50 篇，通过“上一页 / 下一页”浏览。目录页默认收起大类；展开小类后先显示 100 篇，更多内容点击“显示更多…”继续加载。目录搜索自动展开匹配分组；清空搜索后恢复原先的展开状态。侧栏筛选作用于两个界面，两个界面的搜索互相独立。
- **拖动调整宽度**：分类栏与工作区之间、列表与详情／阅读预览之间都有浅紫色分隔条；按住拖动可调宽。鼠标悬停时分隔条变色。表头列与列之间也可拖动调整列宽。
- 分类栏宽度、两个页面各自的列表／预览宽度、列宽、目录折叠状态和上次打开的页面均自动记忆，保存在现有本地索引库中。窗口较小时会保留最小可用宽度，较宽的表格可横向滚动。

## 编辑和使用模型接口

1. 打开设置的“模型接口”页，默认读取当前选用的 API JSON 文件。
2. 点击“打开文件…”选择其他接口文件，或直接修改 Base URL、API Key、模型名称、Temperature、Max tokens。密钥默认遮挡，可勾选“显示”。
3. “编辑原始 JSON”可修改完整配置，点击“应用到表单”暂存修改。“用记事本打开”会打开磁盘上的文件；在记事本保存后，返回设置点击“重新读取”。
4. “测试当前配置”使用当前表单内容发送一段虚构的测试摘要，不写入文件、不发送真实文献。测试可能等待最多约 90 秒，期间界面仍可操作。
5. 点击“保存并使用”写入配置并将其设为当前接口。之后新发起的整理会使用这些配置，无需重启。若要自动调用模型，请将“阅读与整理 → 默认整理方式”设为“大模型”。

保存时校验 JSON 和必要字段，保留已有的 embedding 等额外字段。覆盖配置前创建同目录 `.json.bak` 备份，再原子替换文件；取消设置不写入未保存的修改。备份也含密钥，请按原配置文件保管。为避免批次混用配置，文献正在整理时需等批次完成再打开设置。

## 分类和总结

### 全文 Agent 阅读与论文十问

选中文献，在总结面板或“…”菜单点击“全文 Agent 分析 / 再次分析”。此模式独立于普通整理，会将全部可提取正文按每段 12000 字符发送到当前模型接口，含正文、结论、参考文献与附录。Agent 先生成各段证据笔记，再按问题汇总，并可选择最多 3 个原文段进行一次回读核实。长文分层合并笔记，不静默丢弃末尾内容。

默认按论文十问回答：问题、新颖性、科学假设、相关研究与研究员、创新点、实验设计、代码与数据集、假设是否得到支持、贡献、后续工作。可在“设置 → 全文分析”中逐行修改问题、恢复默认问题及调整每篇调用上限（默认 32）。超出预算时会在发送正文前提示；分段笔记输出最多 1800 token，最终每轮最多 5000 token，输入也计费。设置中的通用 Max tokens 用于普通整理，全文模式使用上述独立上限。

本地缓存以原文内容、问题和接口配置区分。再次分析默认复用证据笔记、重新生成总结；取消复用会重读。文件、问题或接口变化会自动重读。笔记缓存保存在用户数据目录的 `data/analysis-cache`，可以关闭程序后删除以释放空间。此模式不访问外部网站，也不核查外部文献的新颖性。PDF 扫描页需先 OCR；图片及复杂公式可能无法正确提取，结果中标注读取范围。

生成结果写入“研究总结”，更新后可直接被本地搜索检索。重新生成、手动编辑总结时自动保存旧版本；在“总结历史版本”可恢复，恢复前也会保存当前总结。分析失败不会覆盖旧总结。历史版本和缓存不包含在索引 JSON 导出中，完整备份请复制用户数据目录。

### Markdown 与公式编辑

文献信息编辑器采用左右分栏：左侧编辑 Markdown / LaTeX，右侧在应用内实时排版，拖动中间分隔条可调整宽度。摘要、总结和个人描述等标签共用实时预览，切换标签自动更新。工具栏提供加粗、斜体、行内公式、独立公式和插入链接；Ctrl+B / Ctrl+I / Ctrl+K 是对应快捷键。公式使用 `$x_i^2$`、`$$\frac{a}{b}$$`，也支持 `\(...\)`、`\[...\]`。保存后的总结、个人描述及历史总结同样在应用内显示公式。内置离线浏览器排版组件，安装包会比旧版大，无需用户另装环境。

“插入链接”可以填写显示文字、网页地址，或选择本地附件；会在当前光标或选中文字处生成 Markdown 链接。右侧预览和保存后的描述中可点击打开，网页交给默认浏览器，本地文件交给系统默认程序。公式排版仅支持 KaTeX 的 LaTeX 数学语法，不是完整 LaTeX 文档编译器；未完成或错误的公式保留原式，修正后自动重新排版。“排版预览”按钮仍可额外打开独立浏览器预览。

### 普通整理（节省调用）

- PDF 读取前 4 页定位题目、摘要、关键词；读取末尾最多 12 页查找结论和局限，遇到参考文献、附录等标题停止截取。DOCX 流式扫描并只保留末尾最多 60000 字符用于定位结论，文本文件读取末尾最多 96000 字节。不是全文向量化，也不向模型发送整篇文件。
- 模型首轮输入限定为题目（最多 400 字符）、摘要（6000）、关键词（1000）、识别到的结论（5000）和局限段（2500），另附已有分类供复用；个人描述和关联链接不发送给模型。引言只在分类不确定时补充，最多前两段且截断到 4000 字符。
- 模型返回分类不确定时，才在第二次请求附上引言前两段。仍不确定则放入“待分类 / 待确认”。
- 模型总结按研究问题、方法、主要发现、局限组织，局限优先引用作者明确陈述的内容，不把未来工作直接当作已证实的缺陷；无证据时应标明提供内容未说明。请结合原文核对。
- 本地规则可在设置的“分类规则”页编辑。本地与手动模式提供明确标记的摘要、结论和局限摘录，不调用模型。
- 摘要、关键词、结论、局限均缺失时保留索引并标记待补充，不根据文件名猜测总结。扫描 PDF 暂不内置 OCR；双栏、非标准标题或结论不在末尾读取范围内时，可能需要手动补充。
- **旧文献**：搜索页提供“补充旧文献结论（本地读取）”，不会调用模型或重新生成旧总结。之后选中文献点击“整理”可生成包含结论的新总结。旧文献直接重新整理时也会尝试补充尚未读取的结论；已有手动结论会保留。“…”菜单的“读取所选结论”会重新提取并替换对应的结论字段，请在手动修正后谨慎使用。

## 本地搜索文献

- 点击左侧 **搜索文献**，输入研究需求，例如“我想找能耗预测的论文”或“大模型分类有哪些局限”，点击搜索或按 Enter。
- 结果显示文件、命中字段、相关片段、个人描述、总结和关联链接。可直接打开原文件、编辑描述，或将结果拖到分类目录。
- 检索使用标准 BM25 排序、基础中文双字切分、英文词项和有限的中英同义词表。它能处理自然语言中的关键概念，但不是嵌入语义模型，不保证识别任意隐含意图；无结果时可换用关键词／中英文术语。
- 轻量检索层复用现有 SQLite 元数据，在本次会话内按需生成倒排索引；不部署服务、不使用向量数据库。默认 **本地 BM25 模式消耗 0 API token**。首次检索或内容修改后会在后台更新索引。
- 可选 **智能 Agent**：先将问题改写为中英文检索词并选择目录，再执行 BM25，最后由模型核对短片段并说明关联；模型可请求一次更宽泛的本地检索。全程最多两次模型请求，不无限循环。目录菜单最多 60 项（优先与原问题词项相关的目录），选择最多 5 项，审阅最多 12 篇，每篇最多两段、每段 250 字，不发送整篇文献或原文件路径。两次输出上限分别为 400、700 token；输入也收费，页面显示接口返回的实际总 token（如果接口提供）。
- 智能模式使用设置中的 API，仅点击搜索或按 Enter 时运行；刷新文献和切换模式不会自动付费搜索。目录筛选附带全库候选兜底，接口失败自动回退本地结果。模型关联说明可能有误，请结合显示的原文证据核对。
- 搜索范围是全库，与概览和目录页的侧栏筛选互相独立。索引题目、关键词、摘要、结论、局限、总结、个人描述和分类（每字段按保存内容及上限截取），不读取或索引整篇正文。分数仅用于排序，不是匹配概率；未命中不会编造论文。

## 个人描述、链接和自建目录

- “编辑”中的 **个人描述** 可以记录用途、阅读笔记或自定义标签；它参与本地搜索，重新整理不会覆盖。
- **关联链接** 每行一个，可填 `名称 | https://网页地址` 或 `名称 | D:\文献\附件.pdf`，也支持 `file://` 文件链接。保存在本地，最多 30 个；详情页与搜索页提供打开按钮。不要把笔记和链接写进模型总结字段，以免重新生成时被覆盖。
- 在 **文献目录页** 点击 **新建文件夹** 创建顶层文件夹，或点击任意文件夹右侧 **添加** 创建子文件夹，支持三层、五层及更多层级（受操作系统路径长度限制）。新文件夹直接出现在对应位置，名称自动选中，输入中文或英文名称，按 Enter 或点击其他位置保存，Esc 取消，不弹出窗口。重复或非法名称原位提示，可继续更正；刷新不会清空输入。**重命名** 同样原位编辑。空目录会保留，侧栏也显示完整多层树。
- 文献可拖到任意子文件夹；点击父目录会包含其全部后代文献。父文件夹改名同步更新子目录、索引和磁盘路径；删除父文件夹会将所有后代文献移回待分类，保留原文。已有两级分类无需重新导入，新层级兼容保存在原数据库中。模型仍可生成基础两级主题分类，手动锁定的多层路径会保留。
- 从概览列表、目录页或搜索结果中选中一篇／多篇文献，拖到左侧分类或目录页的大类／小类上即可手动归类；拖入大类时归入其“未细分”小类。也可将资源管理器中的原文件直接拖到目标分类。
- 应用所在位置的 **文献目录** 是真实磁盘目录，按“大类/小类”创建文件夹；其中的 `.url` 快捷方式通过 `file://` 指向原文件，文件名带索引编号以区分同名论文。点击 **打开磁盘目录** 可用资源管理器查看。归类同步快捷方式的位置，原文不移动，保留总结、个人描述和链接。手动归类后自动锁定；模型重新整理时保留分类。若希望再次由模型调整，可在编辑窗口取消“保留手动分类”。
- 删除分类后，文献回到“待分类”，仅清理应用生成且未经修改的快捷方式和空文件夹，不删除原文或自行存入的文件。重命名会同步磁盘文件夹。请在应用内进行分类管理；资源管理器中的手工改名不会反向修改数据库。目录同步失败时底部显示原因，可处理后刷新重试。

## 数据与接口

索引和默认选项在 `data/library.sqlite3`，关闭程序后备份该文件即可恢复整个库。原文件仍需自行保留，绝对路径在换电脑后可能需要重新关联。JSON 导出不含接口密钥，当前不提供 JSON 导入。

接口配置沿用已有文件的 `OpenAI` 对象：`base_url`、`api_key`、`model`，以及可选 `max_tokens`、`temperature`。应用使用非流式请求，单次请求的最大输出限制在 4000 tokens 内，配置文件中的较大数值仍会保留。仅在设置中保存修改时改写接口文件。网络错误写入文献状态，可选中文献重试；失败不会抹掉已保存总结。大模型模式会向配置服务发送限定的文献字段，本地模式不联网。

## 验证

运行 `python -m unittest discover -s tests -v` 检查索引去重、持久化、原文件保护、文本解析、两阶段模型分类、规则与打开程序参数，以及接口保存、备份、取消、修改后请求生效和新版界面交互。界面测试只使用临时数据库和虚构示例，在 `output/ui/` 生成界面检查图，不修改正式文献库或真实接口。
