# 文献书架 · 免环境版

Windows：解压完整 ZIP，双击 LiteratureShelf.exe。程序已经包含 Python、Qt 和 PDF 读取组件，无需安装开发环境。

macOS：打开 DMG，将 LiteratureShelf.app 拖到 Applications，再打开应用。分别提供 Apple Silicon 和 Intel 版本。

Linux：解压 tar.gz，在桌面文件管理器中双击 LiteratureShelf；也可双击“启动文献书架.sh”。面向 Ubuntu 22.04/24.04 等现代 x86_64 桌面系统；不是面向所有发行版、服务器或 ARM 的通用二进制。

第一次打开默认使用本地规则和 BM25 搜索，可以离线添加、管理和搜索文献。需要大模型整理或 Agent 搜索时，在设置中填写自己的接口地址、模型名称和 API Key。安装包不包含任何人的 API 密钥或文献库。

程序升级不会清空数据。数据及生成的分类目录位于：
- Windows：%LOCALAPPDATA%\LiteratureShelf
- macOS：~/Library/Application Support/LiteratureShelf
- Linux：~/.local/share/LiteratureShelf（设置了 XDG_DATA_HOME 时使用其对应目录）

原版项目中的 data/library.sqlite3 和 模型接口/api.json 不会打入发布包。迁移时关闭程序，将它们分别复制到以上用户数据目录下同名子目录中；旧配置的 API 文件路径需要在设置中重新选择。原文依然按原路径引用，换电脑后可重新关联。

这些构建未使用付费代码签名证书，也未经过 Apple 公证，因此系统可能要求首次确认来源。请仅运行自己仓库构建的文件，不要全局关闭系统安全保护。

磁盘分类：Windows 使用 .url 原文快捷方式；macOS、Linux 使用符号链接，原文件不复制。分类操作请通过应用完成。

全文分析：选择文献后点击“全文 Agent 分析 / 再次分析”。每篇只发一次请求，直接回答“设置 → 全文分析”的预设问题和独立“补充问题”中的问题，不再分段写笔记、合并或回读。补充问题也可在“编辑文献”保存。相同全文、问题和配置已有完整回答时可以零请求复用。思考模式沿用设置、默认开启。失败保留旧总结，由用户手动重试；全文超过上下文时需使用支持长文的模型。扫描件需先 OCR。

总结历史：重新生成或编辑总结会保存旧版本，点击“总结历史版本”可恢复。分析失败不会覆盖原总结。

编辑：左侧输入 Markdown / LaTeX，右侧在应用内实时显示完整公式，拖动中间分隔条可调整宽度。工具栏提供加粗、斜体、公式和插入链接；Ctrl+B / Ctrl+I / Ctrl+K 可快速编辑。使用 $x_i^2$ 或 $$\frac{a}{b}$$ 输入公式。插入链接可填写网页地址或选择本地附件，预览和保存后的描述均可点击打开。离线排版组件已包含在安装包内；支持数学语法，不编译完整 LaTeX 文档。

全文阅读：双击文献或点击“阅读全文”仍按设置中的原有方式打开。点击独立的“中英对照”按钮进入内置阅读器，PDF 文献左侧直接显示原始 PDF，右侧只显示相同页码的中文译文。点击“生成全文中文 / 对照”才请求翻译，完成后直接使用缓存；长文分段翻译，已完成段落可续传。生成的原文、中文、对照 Markdown 与 assets 图片可一起导出。PDF 原貌由内置 PDF 组件直接显示，中文区不嵌入整页截图；图片内文字不自动翻译。

编辑与缩放：顶部 Markdown 按钮打开内置编辑器。每块内容可切换源码、排版预览或分栏。阅读器支持缩放按钮、Ctrl+滚轮和 Ctrl+0 重置，图片自适应宽度。

首次 AI 导入：识别到可靠论文标题时自动将原文件改为标题名，保留后缀，并更新索引；没有标题则保留原名，同名会自动加编号。已有文献和再次整理不会被批量改名。

阅读预览：章节连续展开，点击标题折叠；点击“弹出完整阅读预览”在独立大窗口阅读全部内容。编辑文献默认最大化，可隐藏题目分类信息，并点击“在大窗口中编辑当前块 Markdown”；完成后先应用回编辑表单，再保存修改。

便签批注：中英对照窗口点击“原文便签 +”或“中文便签 +”，拖动便签标题移动，输入内容自动保存；右上角 × 删除。便签随文档缓存保存为批注.json，导出时一并带出，重新打开可继续编辑。

全文翻译分批：在“设置 → 全文翻译”设置每次页数，默认 5 页（1–20 页）。PDF 按页码分批，无页码文档按文本段处理；跨页句子提供前后文辅助衔接，但译文归属原页，不跨页搬移。PDF 最多两批同时请求模型，每批完成立即保存到对应页，再继续剩余批次。临时断线仅重试当前批次（最多两次），再次生成复用已完成批次。思考模式仍沿用设置；翻译请求连续无数据等待上限为 10 分钟。

未完成译文保存为“中文.翻译中.md”和“中英对照.翻译中.md”，不会覆盖之前的完整译文；重新打开显示已完成内容，点击生成继续。全部完成后保存正式中文及对照文件。概览窗口缩小时会收起统计卡片，列表与预览保持与目录页一致的左右分栏。

PDF 对照翻页：上一页、下一页或页码输入会同时切换 PDF 与中文。PDF 可用滚轮连续阅读，跨页时右侧中文按当前页码切换；中文滚到底部后继续滚动可进入下一页，不按高度比例强拉另一侧。右侧未译页明确提示等待。旧版混排译文不猜测页码，需要点击生成一次建立逐页缓存；旧文件保留到新译文完整生成。便签按页保存。

模型输出约束：每次请求要求只返回合法 JSON，生成的自然语言使用简体中文。启用 JSON 输出模式；接口明确不支持时仅兼容回退该参数，仍保留提示约束和本地校验。翻译按页检查字段、页码、文本和公式图片标记，格式无效时仅重试当前批次，不接受损坏结果。

便签和译文保存：两侧便签都可拖动标题、输入批注、点击 × 删除，按页自动保存。关闭阅读窗口前会获取最后一次编辑并落盘；若正在翻译，则保存已完成结果、停止后续请求，待当前请求结束后关闭。“保存中文译文…”可单独保存已完成的中文 Markdown 及图片；“导出 Markdown 与图片”仍可导出完整资料。
